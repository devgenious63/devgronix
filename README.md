# Devgronix Launchpad

Build DEVGRONIX from scratch: a premium digital technology and software solutions agency website (tagline: "Create. Develop. Grow."). Implement an editorial tech design system with dark and light tokens, floating pill navigation, and a conversion-focused homepage featuring an original tech visual hero, trust strip, 8 core services, curated sample projects (labeled Demo/Concept), agency values, 6-step workflow, tech ecosystem, sample testimonials, and strong CTA. Include dynamic page routes for /services, /services/:slug, /works, /works/:slug, /about, /pricing, and /contact with inquiry form, powered by a centralized data model ready for future admin CMS and database connection.
